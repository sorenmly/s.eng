Basics of the engine and syntax with examples.\hypertarget{gettingstarted_creatingwindow}{}\doxysection{\texorpdfstring{Creating a window}{Creating a window}}\label{gettingstarted_creatingwindow}
To create a window with s.\+eng lib, you\textquotesingle{}ll need to instantiate an object of the class \doxylink{classseng_1_1window}{seng\+::window}. Basically, this class contains all of the code to create a window and managing it.

Its constructor has some parameters. You need to define width, height and the name of the window (title)

See this basic window object\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{classseng_1_1window}{seng::window}}\ my\_window(640,\ 360,\ \textcolor{stringliteral}{"{}framebyframehihi"{}});}

\end{DoxyCode}


This line of code creates the window object with width of 640, height of 360 and its title as \textquotesingle{}framebyframehihi\textquotesingle{}.

The next step is the Game Loop. Your window needs to stay open and listen to when it needs to close (you clicked the close button in your OS). The \doxylink{classseng_1_1window}{seng\+::window} class provides a glfw wrapper function for this, \doxylink{classseng_1_1window_a567d103dbbdb4405b51f20e47608f0fd}{seng\+::window\+::should\+Close()}

Other important thing is to update the events. Every "{}action"{} is an event and it needs to be updated everytime.
