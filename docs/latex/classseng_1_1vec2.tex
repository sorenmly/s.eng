\subsubsection*{template$<$typename T$>$\newline
class seng\+::vec2$<$ T $>$}
Represents a two-\/dimensional mathematical vector. 

A templated vector class that stores two components, x and y. Provides basic vector arithmetic, length calculation, normalization, equality comparison, and stream output.
