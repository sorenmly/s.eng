Detailed Description

template<typename T>
class seng::vec3< T >

Represents a three-dimensional mathematical vector.

A templated vector class that stores three components, x, y, and z. Provides basic vector arithmetic, length calculation, normalization, equality comparison, and stream output.

Template Parameters
TNumeric type used for the vector components.
Example
seng::vec3<float> position(1.0f, 2.0f, 3.0f);
seng::vec3<float> offset(2.0f, 0.0f, 1.0f);
auto result = position + offset;
std::cout << result << std::endl;
