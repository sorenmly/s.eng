Math Library

Mathematical utilities provided by s.eng.

Introduction

The math module provides fundamental mathematical structures and operations used throughout the engine.

Vectors

The library currently provides three vector types:

  • seng::vec2
  • seng::vec3
  • seng::vec4

Supported Operations

All vector types support:

  • Component-wise addition.
  • Component-wise multiplication.
  • Euclidean length calculation.
  • Vector normalization.
  • Equality comparison.

Examples

seng::vec3<float> position(1.0f, 2.0f, 3.0f);
seng::vec3<float> offset(5.0f, 0.0f, 0.0f);
auto result = position + offset;
