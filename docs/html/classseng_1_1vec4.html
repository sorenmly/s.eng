Detailed Description

template<typename T>
class seng::vec4< T >

Represents a four-dimensional mathematical vector.

A templated vector class that stores four components: x, y, z, and a. Provides basic vector arithmetic, length calculation, normalization, equality comparison, and stream output.

Template Parameters
TNumeric type used for the vector components.
Example
seng::vec4<float> color(1.0f, 0.5f, 0.0f, 1.0f);
seng::vec4<float> factor(0.5f, 1.0f, 1.0f, 1.0f);
auto result = color * factor;
std::cout << result << std::endl;
